# 変異度の検証リスト（わかりやすい版）

## この表の使い方

1. ゲームを起動し、**右クリック → デバッグメニュー**で変異度を変えられる状態にする。  
2. 下の **「段階ごとに何が起きるか」** を見ながら、**その％に合うか**だけを確認する。  
3. 本能の声を試すときは、サンドボックスの **Instinct Voice（本能の声）をオン**にする。

---

## 段階早見表（ここが正解のイメージ）

| 画面の％（おおよそ） | ステータス名 | 体の症状・画面 | 台詞（本能オン時） |
| :--- | :--- | :--- | :--- |
| **〜24.99** | Clean | 特になし。画面の暗幕もなし。 | 25% を**下回ったとき**に一度、安心寄りの台詞など |
| **25〜49** | Unstable | 軽いパニック・めまい気味。HP は減らない。 | 25% を**超えたとき**に一度。あとたまに同じ段階の台詞 |
| **50〜74** | Danger | 強いパニック。咳・血・**毎分ちょっとずつ HP 減**。左右が暗くなる。 | 50% を**超えたとき**に一度。あとたまに台詞 |
| **75〜99** | Critical | Danger に加え、発熱っぽいデバフ。**HP がもっと減る**。上下も暗くなる（トンネル）。 | 75% を**超えたとき**に一度。あとたまに台詞 |
| **100** | EVOLVED | **HP がいちばん減る**。足が遅い・走れない・跛行。画面いっぱい暗い。 | 100% **ちょうどのとき**に一度。あとたまに台詞 |

**数字の見方**

- HUD は **`12.34%` のように小数付き**で出る。  
- **帯の切り替え**は **25 / 50 / 75 / 100** ちょうど（未満／以上）で変わる。

---

## 検証の順番（おすすめ）

### A. 画面（HUD）

- [ ] ％が **小数2桁**で出ている。  
- [ ] **24.99** のときチップは **Clean**、**25.00** で **Unstable** に変わる。  
- [ ] バーの長さが％と合っている。

### B. 本能の声（サンドボックスでオン）

- [ ] **25・50・75・100** を**下から初めて超えたとき**、それぞれ段階に合う台詞が出る（50% だけ嘔吐音っぽい音）。  
- [ ] **25% 以上あったあと 25% 未満に下がる**と、Clean 寄りの台詞が出る。  
- [ ] しばらくすると、**今の段階の台詞**がたまに出る（連発しすぎない）。  
- [ ] **本能の声オフ**のときは、上の台詞は**一切出ない**（体の症状は別）。

### C. 体の症状（デバッグで％を動かす）

- [ ] **24% 前後**: パニック・咳・HP 減・画面の暗幕 **なし**。  
- [ ] **30% 前後**: 軽いパニックっぽい。**HP は減らない**。  
- [ ] **55% 前後**: 強いパニック。たまに咳と血。**毎分 HP が少しずつ減る**。画面左右が暗い。  
- [ ] **80% 前後**: 上に加えて画面上下も暗い。**HP がもっと減る**。  
- [ ] **100%**: **いちばん HP が減る**。動きが遅い・走れない・足を引きずる感じ。

### D. 画面の暗さだけ（ズームはしない）

- [ ] **50% 未満**: 暗幕 **なし**。  
- [ ] **50〜74%**: **左右**だけ暗い（上下はまだ軽い／トンネル主役ではない）。  
- [ ] **75% 以上**: **左右＋上下**でトンネル感。**マウスでズームしても「変異の暗さ」とは別**のはず。

### E. 抗変異薬（錠剤を使う）

- [ ] 使うと **変異度が 40〜59 くらい下がる**（目安）。  
- [ ] **HP が一気に減る**・**パニック**が強くなる。  
- [ ] **何も起きない**ときは、ゲームが「食べる」と「薬を使う」で**別処理**の可能性あり（要メモ）。

### F. 最後にざっと

- [ ] デバッグで **0% → 100% → 0%** と行き来して、**速度・画面・台詞**がおかしなまま残らない。  
- [ ] **セーブして再開**しても、％と症状がおかしくならない。

---

## オプション（わかる人向け）

- **毎分の HP 減**: 設計では「10 分で Danger −2、Critical −10、EVOLVED −20」。ゲームは **1 分ごと**なので、だいたい **−0.2 / −1 / −2 毎分**のイメージ。  
- **変異のオンオフ**: `NE.Switches.EnableMutation` がオフだと、**症状・暗幕・本能の声の処理**は動かない想定（変異が溜まる計算だけ別なら、その旨を確認）。  
- **安全圏**: 汚染ゼロの場所で、変異が**ほんの少しずつ下がる**か（自然回復）。
