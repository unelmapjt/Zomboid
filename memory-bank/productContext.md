# Product Context: NOX_EVO_B42

## 1. 製品概要
- Build 42 環境に最適化されたサバイバルMOD。
- プレイヤーは汚染が進む世界で 50 日間の生存を目指す。
- 汚染度を中心とした生存システム、進化したゾンビ、終盤演出を組み合わせる。

## 2. 主要課題
- Build 42 の Lua 実装制約を踏まえ、既存 API の挙動を回避する設計。
- 50日の進行を自然に感じさせるステートマシンとイベント設計。
- B42 APIのブラックボックス性と非決定論的挙動によるハルシネーションの回避。

## 3. 開発・技術スタック
- Project Zomboid Build 42
- Lua 5.1
- **Z-System Infrastructure**:
  - `Z_Core.lua`: 構造化ロガー
  - `Z_Tracer.lua`: 実行時挙動オラクル
  - `.cursorrules`: LLM制御マイクロコード
- B42 `media/lua` 構造に準拠したモジュール配置
- グラフィック・サウンドアセットは原則としてバニラまたは既存のものを流用。

## 4. 成功基準
- B42 環境で起動し、初期化が完了すること。
- 汚染度 HUD、変異ゾンビ、50日目の演出が仕様通りに動作すること。
- 開発過程において、エラーループに陥ることなく、Z-Systemによる単一差分適用でバグが収束すること。
